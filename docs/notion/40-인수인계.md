# 인수인계 가이드

새 개발자가 처음 받았을 때 따라 하는 문서.

## 1. 로컬 개발 환경 셋업

```bash
# 1) 저장소 클론
git clone https://github.com/wlsgur11/PNUAICMS.git
cd PNUAICMS/webapp   # 앱 루트는 webapp 폴더

# 2) Node 20 이상 준비 후 의존성 설치 (CI 는 20, 최소 18.18)
npm install

# 3) 로컬 DB 띄우기 (운영 DB 는 교내망 전용이라 밖에서 못 닿는다)
docker run -d --name cms-local-db -p 5432:5432 \
  -e POSTGRES_USER=cms -e POSTGRES_PASSWORD=cms -e POSTGRES_DB=cms postgres:17

# 4) .env 만들기
cp .env.example .env
#    DATABASE_URL / DIRECT_URL 을 위 로컬 DB 로 맞추고
#    AUTH_BYPASS="true" 로 두면 구글 OAuth 설정 없이 바로 띄울 수 있다

# 5) 스키마 반영
npm run db:push

# 6) 개발 서버 실행
npm run dev   # http://localhost:3000
```

로컬 DB 는 비어 있다. 화면만 보려면 그대로 두고, 데이터가 필요하면 `npm run db:seed` 또는 실적 엑셀을 `/records/import` 로 올린다.

## 2. 자주 쓰는 명령

| 명령 | 용도 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드(prisma generate + 타입체크 포함) |
| `npx tsc --noEmit` | 타입 검사만 |
| `npm run db:push` | Prisma 스키마를 DB에 반영 |
| `npm run db:studio` | Prisma Studio(DB GUI) |
| `npm run db:seed` | 시드 데이터 |

> 윈도우에서 개발 서버를 켜 둔 채 `npm run build` / `prisma generate` / `db:push` 를 돌리면 Prisma 엔진 DLL 이 잠겨 `EPERM rename` 으로 실패한다. **스키마 작업 전에는 dev 서버를 끈다.**

## 3. 비밀값(.env) 위치

`.env` 에는 DB 접속·구글 OAuth·API 키가 들어간다. **저장소에는 없다(커밋 금지).**

- 운영 값: 서버실 PC 의 `~/cms/.env` 한 곳뿐이다.
- 새로 받을 때: 기존 담당자(또는 octopus121)에게 요청.
- 필요한 키 목록과 설명은 저장소의 `.env.example` 에 다 적혀 있다.

## 4. 데이터베이스

- 운영 DB 는 **서버실 PC 안의 PostgreSQL 17 컨테이너**(`cms_db`)다. `127.0.0.1:5432` 에만 바인딩돼 있어 외부에서 직접 못 붙는다.
- 원래 Supabase 를 썼으나 2026-06-30 에 옮겼다. 옛 문서나 주석에 Supabase 가 보이면 낡은 것이다.
- 운영 DB 를 꼭 봐야 하면 SSH 터널로 붙는다(DataGrip 등). 접속 방법은 배포 & 운영 페이지 참고.
- **운영 DB 에 대고 쓰기 작업을 하지 말 것.** 특히 `db:push` 와 실적 엑셀 업로드는 파괴적이다.
- 스키마는 `prisma/schema.prisma`. 변경 시 로컬은 `npm run db:push`, 운영은 배포 후 서버에서 별도로 반영한다.

## 5. 건드릴 때 주의

- **실적 엑셀 업로드**는 산학·인턴십·연도별 현황판을 전체 교체한다. 최신 전체본일 때만 올린다. (기업·연구실·컨택·학생 수동입력분은 보존된다)
- **AUTH_BYPASS**: 운영에서 true 금지. 인증이 통째로 무력화된다.
- **엑셀 파서**(`src/lib/records-*.ts`, `swcu-*.ts`)는 원본 엑셀의 특이한 형식(네임스페이스 접두사, 과학적표기 학번, 시트별 위치 차이)에 맞춰 깐깐하게 짜여 있다. 엑셀 양식이 바뀌면 파서도 점검해야 한다.
- **낙관적 락**: 수정 API 는 `version` 을 같이 받는다. 다른 사람이 먼저 저장했으면 409 가 난다. 클라이언트에서 버전을 빼먹으면 저장이 안 된다.
- **학생 개인정보**: 목록·엑셀은 마스킹(김*혁), 실명은 상세 화면에서만. 이 규칙을 깨는 화면을 새로 만들지 말 것.
