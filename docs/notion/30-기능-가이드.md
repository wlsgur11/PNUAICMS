# 기능 가이드

## 화면 구성

| 메뉴 | 설명 |
| --- | --- |
| 대시보드 | 정량실적 현황판(연도별 산학/인턴 목표·달성률), 기업 관계 요약 |
| 기업 관리 | 기업 리스트, 신규 등록, 엑셀형 입력(그리드) |
| 산학·인턴십 실적 | 산학협력 현황, 인턴십 현황, 실적 엑셀 업로드 |
| SW중심대학 성과 | 성과 대시보드, 실적 엑셀 업로드 |
| 학생 이력 | 학생 현황, 목록, 신규 등록, 통계분석 |
| 사용자 관리 | (슈퍼관리자 전용) 권한 부여 |
| 패밀리 사이트 | 사이드바 하단. AI융합교육원 관련 외부 시스템 바로가기(코드플레이스, AIPMS, 지식검색 등). 새 탭으로 열린다 |

## 자주 하는 작업

### 1) 산학·인턴십 정량실적 엑셀 업로드

- 위치: 산학·인턴십 실적 > 실적 업로드 (`/records/import`)
- 동작: 업로드하면 **산학협력 프로젝트 + 인턴십 + 연도별 현황판이 전체 교체**된다. 기업·연구실·컨택·학생(수동입력)은 보존.
- 시트 인식: `OO년 CSE`, `OO년 DS`, `OO년 SW중심대학 프로그램`, `OO년 인턴십현황`, `OO년 전체현황`, `OO년 산학협력프로젝트`(초기 연도)
- 업로드 후 결과창에 적재 건수와 "CMS에 없는 기업(미매칭)" 목록이 뜬다. 그 기업을 CMS에 등록하면 실적이 자동 연결된다.
- 주의: 같은 파일이 최신 전체본인지 확인하고 올릴 것(전체 교체이므로).

### 2) SW중심대학 성과 엑셀 업로드

- 위치: SW중심대학 성과 > 실적 엑셀 업로드 (`/swcu/import`)
- 위 산학·인턴십 업로드와 다른 엑셀이다(성과지표 전용).

### 3) 사용자 권한 부여 (슈퍼관리자 전용)

- 대상자가 먼저 사이트에서 **구글 로그인 1회** 하면 자동으로 일반(GENERAL)으로 목록에 뜬다.
- 슈퍼관리자가 `/admin/users`에서 그 사람을 관리자/슈퍼로 변경. 변경 즉시 반영.

### 4) 기업 등록 + 자동 채움

- 기업 신규 등록(`/companies/new`)에서 기업명 입력 후 "이름으로 자동 채움" 누르면 외부 공개데이터에서 빈 칸을 채운다.
- 출처: 네이버(소재지·홈페이지), DART(대표자·업종·설립일·매출규모), 공개 임금데이터(연봉). 서버에 해당 API 키가 있는 항목만 동작.
- "특이사항" 칸은 자동 채움 대상이 아니다. 컨택 시 주의점, 다른 교수님 관련 기업 여부 등을 수동으로 메모한다.

## 참고: 데이터 표시 규칙

- 학생 이름은 목록/연결 표시에서 마스킹(김*혁). 실명은 학생 상세에서만.
- 기업 상세의 참여 학생은 산학협력/인턴십으로 구분하고 연도별로 묶어 보여준다.
- 산학·인턴십 목록의 연도 필터는 데이터에 존재하는 연도로 자동 구성된다.
- 일반(GENERAL) 권한은 대시보드만 보인다. 나머지 메뉴는 아예 숨겨지고, 주소로 직접 들어가도 대시보드로 돌아온다.
- 사이드바는 접을 수 있고(아이콘 레일), 다크모드 토글이 하단에 있다. 선택은 브라우저에 기억된다.
